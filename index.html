Flappy Drone

Estudo de caso • Projeto de extensão

O que é

Um jogo em Java com JavaFX em que um drone, o mascote do SENAI, voa entre racks de servidores. Feito em equipe no UNI SENAI como projeto de extensão para uma ONG.

Destaques

  • Modo acessível: física mais lenta, aberturas maiores e colisão tolerante, com hitbox circular.
  • Telas de menu, jogo e fim de jogo organizadas como estados do jogo.
  • Cenário da cidade com parallax, efeitos sonoros e pontuação.
  • Janela que se adapta a qualquer monitor, com tela cheia (F11) para projetor.
  • Empacotado com Maven em um único JAR que abre no Windows e no Linux, com Java portátil.

O que demonstra

Java e JavaFX, código organizado em classes, trabalho em equipe e entrega de um software que qualquer pessoa abre com dois cliques.
